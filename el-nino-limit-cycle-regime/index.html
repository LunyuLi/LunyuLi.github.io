El Nino Limit-Cycle Regime

Code and processed-data page for the manuscript The Existence of El Nino as a Limit Cycle Regime from a Delicate Balance between Stabilizing and Destabilizing Processes.

Manuscript support page. Complete reproducibility materials are being prepared.

Availability Statement

The code and processed data used to reproduce the manuscript figures and numerical analyses will be made publicly available on this page. A permanent Zenodo archive and DOI will be provided before publication.

Planned Public Materials

  • MATLAB scripts used to generate the main and supplementary figures.
  • Processed data files supporting the bifurcation and stability analyses.
  • Documentation for external observational or reanalysis datasets used in supplementary comparisons.
  • A final archived release with a Zenodo DOI.
